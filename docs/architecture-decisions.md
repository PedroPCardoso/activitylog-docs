# Architecture Decisions

Key architectural decisions (D1–D23) from the design grilling sessions.

## Core principles

| # | Decision |
|---|---|
| **D1** | **iff-committed** is the defining invariant: an activity persists iff the mutation commits (when transactional). |
| **D2** | **Core agnostic of ORM + first-class adapters.** One `SqlExecutorStore` for all dialects. |
| **D17** | **MVP anchored on TypeORM; Prisma fast-follow.** TypeORM demonstrates iff-committed cleanly first. |
| **D16** | **Write pipeline: capture diff → beforePersist → redaction → persist.** Redaction is the final guard. |
| **D15** | **Exactly 3 packages** under `activitylog-` prefix, with ORM support inside framework packages. |
| **D14** | **Redaction deny-by-default.** Sensitive field names are redacted before persistence, opt-out is explicit. |
| **D12** | **Outbox deferred to 1.0.** Single `ActivityStore` interface without writer/reader split. |

## Data model

| # | Decision |
|---|---|
| **D11** | **`properties` uses best JSON type per dialect** (`jsonb` PG, `JSON` MySQL, `TEXT` SQLite). |
| **D10** | **`bigint` PK default, `uuid` v7 configurable.** Default serves 99% of cases. |
| **D9** | **Aggregate = 1 activity** with `subject_id=null`, never expanded to per-row. |
| **D8** | **Old values without lock by default**, `lockForDiff: true` as opt-in. |
| **D4** | **Identity: opaque string types, varchar ids.** Core never interprets `*_type`. |
| **D19** | **`created_at` is UTC generated by the application**, with `created_at + id` tiebreak ordering. |

## Context and framework

| # | Decision |
|---|---|
| **D6** | **ALS opened early (middleware), causer resolved lazily (at `.log()`).** |
| **D5** | **Context via ALS singleton in core.** Shared dependency, never bundled in leaves. |
| **D7** | **Queue boundary = explicit contract.** `serializeContext()` / `runWithContext()` helpers. |
| **D3** | **Iff-committed only guaranteed by explicit transactional helpers.** Decorators/extensions are best-effort. |
| **D18** | **Query API: strong types for fixed columns, free-form path for `properties`.** |
| **D20** | **`LogOptions` composes by precedence.** `logOnly` and `logExcept` are mutually exclusive at the same level. |

See the full decision log with rejected alternatives and rationale at the [GitHub repo](https://github.com/PedroPCardoso/activitylog/blob/main/docs/ARCHITECTURE.md).
